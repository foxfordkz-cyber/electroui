ЭлектроҮй — «Үйдегі электр құралдары» (веб-нұсқа)
====================================================

ТАПСЫРМА
--------
«Үйдегі электр құралдары»:
  1) электр құралдарының класс иерархиясын анықтау;
  2) кейбір құралдарды розеткаға қосу;
  3) тұтынылатын қуатты есептеу;
  4) пәтердегі құралдарды қуаты бойынша сұрыптау;
  5) пәтерден берілген параметрлер аралығына сәйкес құралды табу.
Қосымша: тіркелу, кіру, құпиясөзді хэштеу, ADMIN және CLIENT рөлдері, SQL дерекқор,
хабарламалар, сайдбар, тақырыптар (жарық/қараңғы + акцент түстер), 3D анимация, видео мен суреттер.

ІСКЕ ҚОСУ
---------
1. Компьютерде Python 3 орнатылған болуы керек (3.10+; тексерілгені — Python 3.14).
   Қосымша кітапхана ОРНАТУДЫҢ ҚАЖЕТІ ЖОҚ — тек стандартты кітапхана қолданылады.
2. start.bat файлын екі рет басыңыз (немесе терминалда:  python server.py).
3. Браузерде ашыңыз:  http://localhost:8090
   Телефоннан: компьютер мен телефон бір Wi-Fi-да болса, сервер терезесінде көрсетілген
   http://192.168.x.x:8090 адресін ашыңыз.
4. Тоқтату: сервер терезесінде Ctrl+C.

Портты өзгерту:  set PORT=9000  &&  python server.py
Дерекқорды бастапқы күйге қайтару:  python server.py --reset   (немесе electroui.db файлын жойыңыз)
Интернет қажет емес — three.js (static/three.min.js), суреттер мен видеолар жергілікті.

ТЕСТ АККАУНТТАРЫ
----------------
  Әкімші (ADMIN):  логин  admin   құпиясөз  Admin123!     (Әкімші)
  Клиент (CLIENT): логин  aru     құпиясөз  Aru12345!     (Ару Серікқызы, демо-пәтері бар)
Кіру бетінде «Тест аккаунттары» батырмаларын басса, форма өзі толтырылады.
Жаңа клиент «Тіркелу» қойындысы арқылы тіркеледі — оған 4 бос бөлме беріледі:
Ас үй (4 розетка), Қонақ бөлме (5), Жатын бөлме (3), Жуынатын бөлме (2).

«aru» демо-пәтері:
  Ас үй:           Электр шәйнек (қосулы), Тоңазытқыш (қосулы), Микротолқынды пеш
  Қонақ бөлме:     Теледидар (қосулы), Кондиционер, Шам (қосулы), Компьютер, Шаңсорғыш
  Жатын бөлме:     Майлы жылытқыш, Желдеткіш, Шам
  Жуынатын бөлме:  Кір жуғыш машина, Үтік
Басында қосулы қуат 2 470 Вт. Шектен асуды көрсету үшін: Микротолқынды пеш, Кондиционер,
Компьютер, Майлы жылытқыш және Кір жуғыш машинаны қосыңыз → 8 970 Вт > 7 000 Вт → ескерту.

БӨЛІМДЕР (сол жақ мәзір)
------------------------
  Басты бет        — жүктеме датчигі (%), қосулы құралдар саны, жалпы Вт, А, кВт·сағ/тәулік, ₸/ай,
                     бөлмелер бойынша диаграмма, санаттар бойынша қуат, шамадан тыс жүктеме баннері,
                     «Барлығын өшіру», соңғы оқиғалар, тапсырманың 5 қадамы.
  Тапсырма         — тапсырма мәтіні, әр қадам кодта қай жерде орындалғаны, қосымша талаптар тізімі.
  Иерархия (1)     — интерактивті класс ағашы (қазақша атаулар + Java/JS класс аттары, өрістер, әдістер,
                     интерфейстер, Java коды), тірі демо: фабрика, instanceof, полиморфты describe()
                     (JS нәтижесі мен Python нәтижесі қатар), абстрактілі класстан объект жасау қатесі.
  Менің пәтерім (2)— бөлмелер, розеткалар (бос/бос емес), фотосы бар құрал карточкалары, «Розетка»
                     ауыстырғышы, каталогтан немесе өз құралын қосу, өзгерту, жою.
                     Бос розетка болмаса: «Бұл бөлмеде бос розетка жоқ».
  Қуатты есептеу(3)— кесте: P, U, I = P/U, t, E = P·t/1000, ₸/ай, жиынтық жол, формулалар,
                     жүктеме датчигі, әр құралдың үлесі, мини-калькулятор, Python≡JS тексеруі.
  Сұрыптау (4)     — қуаты (негізгі), атауы, энергия класы, кВт·сағ бойынша; өсу/кему;
                     анимациялы рейтинг жолақтары; Python / Java / SQL / JS коды.
  Іздеу (5)        — қуат, кернеу, салмақ, жұмыс уақыты аралықтары (min–max), энергия класы,
                     санат, бөлме, тек қосулылар, атауы. Серверде параметрленген SQL (BETWEEN ? AND ?)
                     орындалып, SQL мәтіні мен параметрлері көрсетіледі.
  3D пәтер         — three.js: 4 бөлмелі жоспар, әр тип үшін low-poly модель, электр қалқанынан
                     құралдарға сымдар; қосулы құралдар жарқырап, сым бойымен ток бөлшектері ағады.
                     Сүйреп айналдыру, дөңгелекше/екі саусақпен масштаб, оң батырма/Shift — жылжыту.
                     Құралды басса — ақпарат және розеткаға қосу/ажырату. WebGL жоқ болса — 2D жоспар.
  Медиа            — 4 видео, 14 фото галереясы (лайтбокс, ←/→, свайп), авторлары, үнемдеу кеңестері.
                     Видео файлы жоқ болса — постер және «Видео әлі қосылмаған» жазуы шығады.
  Хабарламалар     — WARNING / SUCCESS / INFO / BROADCAST; оқылды, жою, сүзгі; оқиғалар тарихы;
                     браузердің Notification API рұқсатын сұрау. Жоғарғы қоңыраушада оқылмағандар саны.
  Профиль          — аты-жөні, email өзгерту; құпиясөзді өзгерту (ескісі хэшпен тексеріледі).
  Баптаулар        — жарық / қараңғы / жүйелік тақырып, 4 акцент түсі (көк, жасыл, қызғылт сары,
                     күлгін), анимацияны азайту, мәзірді жию. Таңдау браузерде (localStorage) сақталады.
  ӘКІМШІ ғана:
  Пайдаланушылар   — тізім, рөлін өзгерту, бұғаттау/ашу, жою (өзін жоя/түсіре/бұғаттай алмайды).
  Каталог          — құрал үлгілерін қосу / өзгерту / жою.
  Жалпы статистика — барлық пайдаланушылар бойынша 10 SQL есеп (COUNT/SUM/AVG/MAX, JOIN,
                     LEFT JOIN, GROUP BY, HAVING, ішкі сұраныс, CASE), әрқайсысының SQL мәтіні.
  Хабарлама жіберу — барлық клиенттерге BROADCAST хабарлама + жіберілгендер тарихы.
  Тариф пен лимит  — тариф (25 ₸/кВт·сағ), пәтер шегі (7 000 Вт ≈ 32 А × 220 В), бөлме шегі (3 500 Вт).

Рөлдер СЕРВЕРДЕ тексеріледі: CLIENT /api/admin/... сұрауын жіберсе, сервер 403 қайтарады.

КОД ҚАЙДА
---------
  server.py
    1-бөлім  ООП: Pluggable, Heating интерфейстері, ElectricAppliance (абстрактілі),
             5 санат класы, 12 нақты класс, create_appliance() фабрикасы, Room, Apartment
             (total_power, daily_kwh, monthly_cost, sorted_by, find). Python кластары
             сервердегі есептеу мен сұрыптауда қолданылады.
    2-бөлім  SQL дерекқор: SCHEMA (CREATE TABLE ... users, sessions, settings, appliance_types,
             rooms, catalog, appliances, notifications, events — сыртқы кілттер, CHECK шектеулері),
             seed() — бастапқы деректер, барлық сұраныстар параметрленген (?).
    3-бөлім  Қауіпсіздік: hash_password() — hashlib.pbkdf2_hmac('sha256', ..., 16 байт тұз,
             120 000 итерация), нәтиже hex; verify_password() — hmac.compare_digest;
             сессия: secrets.token_urlsafe(32), cookie HttpOnly + SameSite=Strict, дерекқорда
             токеннің SHA-256 хэші сақталады; 5 қате әрекеттен кейін логин 30 секундқа бұғатталады.
    4-бөлім  API: get_search() (BETWEEN ? AND ?), get_sort(), do_plug(), check_overload(),
             REPORTS (әкімші статистикасы), әкімші әрекеттері.
    5-бөлім  HTTP: статикалық файлдар, видео үшін Range (206 Partial Content), рөл тексеру (403).
  static/model.js   — сол иерархия JavaScript кластары ретінде (браузерде: карточкалар, есептеу,
                      иерархия беті, Apartment.sortByPower(), findInRange()).
  static/app.js     — бір беттік қосымша (беттер, сайдбар, хабарламалар, тақырыптар, тосттар).
  static/scene3d.js — three.js сахналары (кіру беті және 3D пәтер), өзіміз жазған орбита басқаруы.
  static/app.css    — стильдер, тақырыптар, адаптивті орналасу (телефон ені 375 px-ке дейін).
  media/            — суреттер, видеолар, credits.json (авторлар). IMAGE_SOURCES.txt — дереккөздер.
  electroui.db      — SQLite дерекқоры (бірінші іске қосқанда автоматты жасалады).

Android қосымшасы (ElectroUi) дәл осындай класс иерархиясын, типтерді (KETTLE, FRIDGE, ...),
каталогты, бөлмелерді, тариф пен шектеулерді қолданады.
